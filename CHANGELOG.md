# Changelog

## 0.1.0 — initial public preview (unreleased)

- GLB visual runtime, skeletal animation and GPU skinning with CPU fallback.
- Visual API, animation events, socket queries and server-driven visuals.
- Optional Paper world-background integration.
- Removed private test assets and model-specific defaults for public distribution.
- Added build documentation and CI configuration.

Runtime compatibility and performance remain to be validated for this release.
